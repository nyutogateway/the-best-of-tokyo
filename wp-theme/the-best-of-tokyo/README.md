# THE BEST OF TOKYO 後世に残す言葉 — WordPress テーマ

静的サイト（`the-best-of-tokyo/`）を、そのままの見た目で WordPress から更新できるようにしたテーマです。
本番URL: **https://the-best-of-tokyo.com**

CSS・JavaScript は静的サイトのものをそのまま入れています（`assets/`）。
**class 名を変えると見た目が崩れます**。デザインを直すときは静的サイト側と同じファイルを直して、両方にコピーしてください。

---

## 1. 必要なもの

| | |
|---|---|
| WordPress | 6.0 以上 |
| PHP | 7.4 以上（8.x 推奨） |
| 必須プラグイン | **Advanced Custom Fields**（無料版で動きます） |
| 任意プラグイン | Contact Form 7（入れなくてもお問い合わせフォームは動きます） |

ACF の入力欄はテーマに同梱しています（`acf-json/`）。**インポート作業は不要**で、プラグインを有効にすれば出てきます。

## 2. 入れ方

1. `the-best-of-tokyo` フォルダごと `wp-content/themes/` に置く（または ZIP にして「テーマを追加 → テーマのアップロード」）
2. プラグイン **Advanced Custom Fields** を有効化
3. テーマ「THE BEST OF TOKYO 後世に残す言葉」を有効化

有効化した時点で、次のものが自動で作られます。

- **業種** 10件（医療／介護・福祉／食と農／ものづくり／技術・IT／暮らしの基盤／小売・装い／スポーツ／教育・人材／経営・資産）
- 固定ページ **お問い合わせ**（`/contact/`）と **プライバシーポリシー**（`/privacy/`）

最後に「設定 → 表示設定」でトップページの表示を決めてください（固定ページでも「最新の投稿」でも、トップは `front-page.php` が使われます）。

## 3. 記事（掲載者）の作り方

### 3-1. Word 原稿から取り込む（おすすめ）

**掲載者 → 原稿取り込み**

インタビュー原稿の `.docx` を選ぶと、中身を確認したうえで**下書き**として登録します。複数まとめて選べます。

原稿の形（段落を上から順に読みます。空の段落は無視します）

| 位置 | 内容 |
|---|---|
| 1〜6段落目 | キャッチコピー／英字名／氏名／肩書き／プロフィール／URL の順 |
| 本文 | 中見出し → `Q：`質問 → `A：`回答 のくり返し |
| 最後 | メッセージ見出し（1行）→ メッセージ本文 |

- 中見出し・メッセージ見出しは**短い1行で、「。」で終わらない**こと（これで見出しと判定しています）
- 回答が長いときは、2段落目以降に `A：` を付けなくて構いません
- `※` で始まる段落（制作メモ）、画像、表、テキストボックスは読みません
- 肩書きは「株式会社○○　代表取締役」のように**全角スペース等で区切る**と、会社名と役職に自動で分かれます
- Google ドキュメントの原稿は「ファイル → ダウンロード → Microsoft Word（.docx）」で保存してから選んでください
- 同じ原稿を二重に登録しないよう、取り込んだファイルの中身と名前を記録しています。同じものを選ぶと「取り込み済み」と出ます
- アップロードしたファイルはサーバーに残りません（読んだ内容を1時間だけ一時保存します）

取り込んだあとに、編集画面で次を入れてください。

1. **業種**（トップの GROUP 01〜 の振り分け）
2. **企業ロゴ**（カードの表・ファーストビュー背面のロゴの壁）
3. **アイキャッチ画像**（カードの正方形写真。マウスを乗せるとロゴから切り替わります）
4. 記事ページの人物写真（縦長）
5. 本文の各章の写真（章の見出しのすぐ下に画像ブロックを置く）
6. 流し写真（記事の途中を横に流れる帯。入れなければ出ません）

### 3-2. 手で書く

**掲載者 → 新規追加**

- **タイトル** … 氏名
- **本文**（エディタ）
  - 見出し **H2** が章の区切りになります（CHAPTER 01、02 …）
  - **いちばん最後の H2 は MESSAGE 章**になります
  - 段落を `Q：` `A：` で始めると質問・回答の体裁になります
  - 章の中に置いた画像は、見出しのすぐ下に大きく出ます
- **右側のパネル**
  - アイキャッチ画像 … トップのカードの正方形写真
  - 業種 … チェックを入れる（1つ）

## 4. 画面の対応表

| 画面の場所 | どこで直すか |
|---|---|
| ファーストビューのロゴ・リード文 | 外観 → カスタマイズ → サイトロゴ／サイト文言 |
| ファーストビュー背面のロゴの壁、流れるロゴの帯 | 掲載者の「企業ロゴ」から自動で組み立て |
| ABOUT（企画について）の文章 | 外観 → カスタマイズ → サイト文言 |
| STORIES のグループ（01〜） | 掲載者 → 業種（名前・英字表記・表示順） |
| カードの並び | 掲載者 → 並び替え（ドラッグ） |
| INDEX（掲載者・企業一覧） | 業種と掲載者から自動 |
| 放送局のご紹介（TOKYO MX） | 外観 → カスタマイズ → サイト文言 |
| 放送エリア図 | 外観 → カスタマイズ → サイト文言 → 放送エリア図 |
| フッターの表記 | 外観 → カスタマイズ → サイト文言 → フッターの表記 |
| プライバシーポリシー | 固定ページ「プライバシーポリシー」 |
| お問い合わせ | 固定ページ「お問い合わせ」 |

### 業種（グループ）について

- **掲載者 → 業種** で名前・英字表記（MEDICAL など）・表示順を編集できます
- 表示順の小さい順に 01、02 … と番号が振られ、**2つで1行**にまとまって一定時間ごとに入れ替わります
- トップのカードは1グループ **5人まで**（CSS が5列で組まれているため）。6人目以降は INDEX に出ます
- 掲載者が1人もいない業種は、トップに出ません

### 文章の書き方（カスタマイザー）

ABOUT の文章は、次の決まりで組み立てます。

- **1行＝表示上の1行**（Enter で改行）
- 行の中で折り返したくないまとまりは **`｜`** で区切る
- **`《 》`** で囲んだところは金色の強調（`<em>`）になります

例:

```
時代を超えて受け継がれる｜《「一生モノの言葉」》を、
未来へ届けていきます。
```

## 5. お問い合わせフォーム

初期状態では**テーマ内蔵のフォーム**が動きます（`wp_mail` で送信。宛先は「設定 → 一般 → 管理者メールアドレス」）。

宛先を変えたいときは、子テーマや functions.php に次を足してください。

```php
add_filter( 'tbt_contact_to', function () {
	return 'info@example.com';
} );
```

Contact Form 7 を使う場合は、固定ページ「お問い合わせ」の本文にショートコードを貼ってください。
貼った時点で内蔵フォームは自動的に消えます（意匠クラス `.p-form` はテーマが自動で付けます）。

## 6. ファイルの構成

```
the-best-of-tokyo/
├─ style.css              テーマ情報（見た目はここには書かない）
├─ functions.php          読み込み・カスタマイザー・本文の組み直し・部品
├─ header.php / footer.php
├─ front-page.php         トップ
├─ single-story.php       掲載者の記事ページ
├─ page.php               固定ページ（プライバシーポリシーなど）
├─ page-contact.php       お問い合わせ（スラッグ contact で自動適用）
├─ 404.php / index.php
├─ inc/
│   ├─ cpt.php            掲載者（story）・業種（industry）
│   ├─ docx-import.php    原稿取り込みの画面
│   ├─ docx-parser.php    .docx の読み取り（WordPress に依存しない部分）
│   ├─ reorder.php        並び替え画面
│   ├─ contact-form.php   フォームの送信処理
│   ├─ ogp.php            OGP・meta description・構造化データ
│   └─ setup-pages.php    有効化時の初期設定（業種・固定ページ）
├─ acf-json/              入力欄の定義（自動で読み込まれます）
└─ assets/                静的サイトと同じ CSS / JS / 画像
    ├─ css/   foundation, layout, component, project-top, project-article, project-page（+ admin）
    ├─ js/    main.js（+ admin-reorder.js）
    └─ img/   ロゴ・トロフィー・放送エリア図・サンプルの企業ロゴ
```

掲載者をまだ登録していないあいだは、ファーストビューのロゴの壁と流れる帯に
`assets/img/logos/` のサンプルロゴを使います。掲載者に企業ロゴを登録すると、自動でそちらに入れ替わります。

## 7. 直すときの注意

- **class 名は変えない**（CSS と JavaScript が静的サイトのものをそのまま使っています）
- CSS・JS を直したら、静的サイト側の同じファイルにも反映する（ズレると次の更新で戻ってしまいます）
- 放送エリア図は国土数値情報（国土交通省）の行政区域データから起こしたものです。**フッターの出典表記は消さないでください**
- 記事ページのタイトルタグは「キャッチコピー｜サイト名」になります（キャッチコピー未入力なら氏名）
