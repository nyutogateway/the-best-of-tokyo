# 放送エリア図を作り直すときは

`assets/img/area-map.svg`（放送局のご紹介に置いている図）は、ここの `makemap.py` で作っています。
**県境は実データから起こしたもの**で、手描きではありません。

## 出典

国土数値情報（国土交通省）の行政区域データ。
取得は [dataofjapan/land](https://github.com/dataofjapan/land) の `japan.geojson` を経由しています。
**出典の表示が必要なデータなので、図のキャプションに「国土数値情報（国土交通省）を加工して作成」と入れてあります。消さないでください。**

## 手順

```sh
curl -sS -o japan.geojson https://raw.githubusercontent.com/dataofjapan/land/master/japan.geojson
python3 makemap.py          # → area-map.svg
cp area-map.svg ../../assets/img/area-map.svg
```

## 中身

- 投影は正距円筒。**経度に cos(35.71度) を掛けてある**ので、この縮尺では「円＝送信所から等距離」として扱えます
- 中心は東京スカイツリー（北緯35.7101／東経139.8107）、縮尺は 1km ＝ 3.953px
- 県境は Ramer–Douglas–Peucker で 0.7px まで間引き、画面の外にしかない島と小さい島は落としています
  （東京都の島しょ部は枠の外なので入りません）
- 放送対象地域の東京都だけを金で塗り、周辺の県は細い罫の気配だけにしています
- **市の点は、受信エリア（50km）の中にあるものだけ**を出します（`makemap.py` が距離で振り分け）。
  入っていない街を載せてもエリア図として意味がないためです。
  いまの一覧では 古河・行田・東松山・厚木 が外れます
- 円は半径50km。**実際に受信できる範囲は建物や地形で変わる**ので、キャプションでそう断っています

## 注意

- 枠の範囲（`HALF_W_KM` / `HALF_H_KM`）を変えると縮尺も変わります。円の半径はkmから計算しているので自動で追従しますが、
  文字の位置は見て調整してください
- 正式なエリア図を使うなら、TOKYO MX の図を許諾を得て差し替えるのが確実です
