# トロフィーのカップを作り直すときは

`assets/img/trophy.webp`（FVのトロフィー）は、ここにあるレンダラで作っています。
手描きのベクターでは金属が周りを映す見え方までは届かず、照りを描き足すほど汚れて見えたため、
カップも台座も実際に光を計算して焼き込んだものです。
いまはロゴとトロフィーを切り離して並べているので、画像にはロゴを含みません。

## 何をしているか

`render.html` は WebGL のフラグメントシェーダで動くレイトレーサです。外部ライブラリは使いません。

- かたちは**5稜の星＋円柱の台**（いただいた実物の例に寄せたもの。鏡面の星が斜めに立ち、
  台に根元が差し込まれている形）。星は板を切り抜いただけだと安っぽいので、
  **中心を厚く・先端を薄く**して稜を作っています（`th = 0.035 - 0.26 * star`）
- **星は大きく傾けます**（まっすぐ立つと記念品に見えません）。実物の例に合わせて、
  画面では時計回りに20度。**`map2` の回転は「世界→星の座標」なので、見た目は符号が逆に効きます**
  （画面で時計回りにしたいなら `rotZ(+0.35)`）。傾けたぶん下の腕は左下を向くので、
  星の中心を右（x=+0.34）へ寄せて、腕が台の真上に来るようにしています
- 星の高さと台の太さの取り合いが要点：**星を下げすぎると、下の2本の腕が台の横腹に
  刺さって、薄いヒレのような余計な面が出ます**
- 仕上げは鏡面（`ROUGH = 0.014`）。実物は磨き上げで、周りの明暗をはっきり映します
- 以前のカップ（回転体＋トーラスの取っ手＋箱の台座）は `profile.py` ともども残してあります。
  戻すときは `map2` を書き戻してください
- 金は GGX の金属。環境は紺のスタジオで、**上は明るい空・下は暗い床・地平に明るい帯**、
  そこへ主光（左上）・上・右の補助・逆光・床の照り返し・**カメラの後ろの白い面**を置いています。
  最後の「白い面」が要点で、器の胴はここを映します。これがないと胴だけ中間調のままで、
  つや消しの真鍮に見えます
- 器どうしの映り込みを1回だけ追っています（取っ手が器に映る、カップが天板に映る、など）
- 台座は箱を3つ。銘板は「枠を彫り込んで、その底に紺の板をはめる」形です（紺の板を金の中に
  置くだけでは、金にすっぽり包まれて見えません）。材質は `map2` が距離と一緒に返します

## 手順

```sh
python3 profile.py                      # 断面 → profile.glsl（render.html に貼り直す）
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new \
  --allow-file-access-from-files --window-size=1500,1400 --virtual-time-budget=1200000 \
  --dump-dom "file://$PWD/render.html" | python3 extract.py     # → cup.png（1100×1387）
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new \
  --allow-file-access-from-files --virtual-time-budget=30000 \
  --dump-dom "file://$PWD/resize.html" | python3 extract2.py    # → cup_small.webp（760×958・50KB）
cp cup_small.webp ../../assets/img/trophy.webp
```

## 注意

- **GPUは1回の描画が長いと途中で打ち切られます**。そうなると絵がまだらに欠けます。
  画面を帯に分けて描いていて（`STRIPS`）、いまは 560 本・AA 2×2・反射のサンプル 9・
  レイマーチ 78 歩で通っています。**これ以上重くすると欠けます**（AA 3×3 も、
  反射14 のまま台座を足したときも欠けました）。
  質を上げたいときは、帯を増やすのではなくサンプルを減らして枚数を重ねる形にしてください
- **画角を変えたら CSS の置き場所も計算し直すこと**。いまの画角は
  `uView`（半幅2.40・半高2.35）と `tgt`（0, 0.65, 0）で、もとのベクター時代の座標で
  x[40,520] y[75,545] を覆います。CSS 側は `.p-hero__meta` の
  `--cup-w`（0.8571）／`--cup-x`（0.0714）／`--cup-y`（0.0518）で置いていて、
  トロフィー本体と足元の映り込みが同じ値を使います
- ロゴはもうこの画像に含みません（トロフィーとロゴは別々に並べる形に変えました）
