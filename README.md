# THE BEST OF TOKYO 後世に残す言葉

静的サイト一式。WP化を見据えて、記事ページは `stories/` 配下に1ファイル1記事で分離しています。

構成は既存シリーズ（spotlight-miyazaki / kumamoto-futureleaders 等）を踏襲しています。

TOP: FV → 企画について → 50 STORIES 表示帯 → グループ 01〜05（各10名・1段5枚で自動送りする横スライダー）→ INDEX 掲載者一覧 → 放送局のご紹介 → footer（局ロゴ／企画ロゴ／copyright）

TV番組ではなく TOKYO MX 公式サイト連動のインタビューメディアなので、グループ分けは放送回ではなく企画側の区切り（01〜05）です。

## ファイル構成

```
index.html            TOP
stories/01.html〜50.html  記事ページ（本文・氏名・写真は OKAYAMA FUTURE VOICE の23記事を巡回して流し込み）
privacy.html          プライバシーポリシー
contact.html          お問い合わせ
assets/css/          CSS（FLOCSSで6ファイルに分割。下記）
assets/js/main.js     ヘッダー状態・SPメニュー・掲載者スライダー（依存ライブラリなし）
assets/img/           ロゴ各種・プレースホルダ
```

## 画面幅の対応

3段で作っています。**メディアクエリは各CSSの末尾にまとめてあります**（基本のルールより後ろに置かないと打ち消せないため。実際に、下層ページのSP指定が前方にあって効いていない不具合がありました）。

| 幅 | 主な切り替え |
| --- | --- |
| 1024px 以上 | カードは5枚を横一列。記事の写真は本文に回り込み（右50%）。中扉は左に積む |
| 768〜1023px（タブレット） | カードは3枚＋2枚の2段。記事の写真は回り込みをやめて本文の上へ（最大620px・中央）。関連カードは2列。ポートレートの欄は 240〜320px |
| 767px 以下（SP） | カードは2枚並び。グループ見出しは折り返して NEXT を右端へ（次のグループの和名は省略）。中扉・グループは1列。フォームは項目名を上、入力欄を下に。日輪マークは中央に薄く |

## SEO・配信まわり

- 各ページに `og:title` / `og:description` / `og:image` / `og:site_name` / `og:locale` / `twitter:card` を用意。OGP画像は `assets/img/ogp.png`（1200×630。ロゴ＋日輪マーク＋局の配色帯＋TOKYO MXロゴ）
- **構造化データ（JSON-LD）**を各ページに。TOPは `WebSite` と `Organization`、記事は `Article`（見出し・説明・写真・`about` に人物と会社）。`<script type="application/ld+json">` は実行されるスクリプトではないためデータとして入れています（プロジェクトの「インラインscript不使用」の例外はここだけ）
- `robots.txt` と `sitemap.xml`（全53ページ）を追加
- お問い合わせ／プライバシーポリシーの `noindex` を外しました（通常の固定ページとして検索対象にするため）
- **公開ドメインが決まったら差し替えが必要**: `robots.txt` と `sitemap.xml` の `https://example.com`、および各ページの `og:image`・JSON-LDの画像パス（相対指定のままでも多くのクローラは解決しますが、絶対URLが確実です）

## 設計メモ

- **カードのローマ字はベタ塗りの小さなラベル**（12.5px・字間0.2em・グループ色の暗い方）。写真には重ねません。**一度は縁文字にして写真に重ねましたが、50名の写真は明暗がまちまちで暗い背景では輪郭が沈んで読めなくなるため戻しました**（背景ぼかしの帯・下端のグラデーション溶かしも同時に撤去）
- **カードのローマ字は姓と名で改行**しています（`<br>` をHTMLに直書き）。2行になったぶん文字を大きく（38〜46px）でき、写真への重なりも深くしています。日本語の氏名は1行のままです
- **高級感寄せの判断（後段）**：要素を足す方向をやめ、①縁文字→ベタ塗り ②背後の袋文字を撤去、の2つを引きました（③ホバーの虹色も一度は墨に落としましたが、そこは戻しています）。虹色は細い罫（読み進みバー・セクションの区切り）とグループの番号／罫線に限定して残しています
- **高級感の調整**：カードは枠線をやめて余白で見せ、ホバーは6px持ち上げるだけ。見出し・氏名の字間を広げ（0.06→0.12〜0.2em）、本文の行間を2.2→2.35に、セクションの余白を約2割増やしました。画像の拡大やホバーのトランジションも0.6〜1.1秒とゆっくりにしています
- 記事の写真帯は1画面5枚。写真の縦横比に左右されないよう、高さではなく**幅を `20vw` に固定**しています（SPは46vw）
- 掲載者一覧はグループごとの横スライダー。カードは縦組み（正方形写真の下に情報）で、768px以上は**1段5枚**。1グループ10名のうち5名が見え、残りは流れて出てきます。カード幅は `18vw` で、間隔込みでちょうど画面幅5枚ぶんになります。**帯だけコンテンツ幅を抜けて画面いっぱい（100vw）に流れます**
- **自動送り**は3枚ずつのコマ送り。1回の移動は420ms、`1 - (1-t)^4`（出だしが速く最後にすっと止まる）で動かしています。ブラウザ標準の `behavior: "smooth"` より短くキレのある動きにするため、自前のアニメーションにしてあります
- 位置合わせは**カード1枚ぶんを基準**にしています。送り幅（3枚）が1周（10枚）を割り切らないため、送り幅基準だと位置が合わなくなるためです。実測で12回送っても 3→6→9→2→5→8→1→4→7→0 とすべてカードの区切りに乗り、ズレは出ません
- **自動送り**は768px以上のみ。**グループごとに向きと速さを変えています**（01=左19px/s、02=右15、03=左23、04=右17、05=左21）。右へ流す列は左端で詰まらないよう1周ぶん進んだ位置から開始します。**同じ並びを3セット複製して1セットぶん進んだら位置を戻す**ことで継ぎ目なくループします（複製側の `<a>` は `aria-hidden="true"` と `tabindex="-1"` で読み上げ・タブ移動から除外。SPでは `display: none`）。**カーソルを乗せても止まりません**（ご指示）。止まるのはキーボードフォーカスがある間とタブが非表示の間だけで、カードを押したあと・矢印操作のあとは2.6秒おいて再開します。`prefers-reduced-motion: reduce` では動きません
- 自動送りと `scroll-snap` は競合するので、768px以上ではスナップを切り、矢印の送り幅の基準としてのみ `scroll-snap-align` を残しています（767px以下はスナップのまま・自動送りなし）
- **768px以上では手でスクロールできません**（`overflow: hidden`）。ドラッグ・スワイプ・ホイールでは動かず、自動送りと矢印だけで動きます。`overflow: hidden` でも `scrollLeft` / `scrollBy()` の書き換えは効くので、写真帯と同じ作りです。767px以下は `overflow-x: auto` のまま手でスワイプできます
- 章の写真は `float: right` で本文を回り込ませています（先方の `single__story__img` と同じ挙動）。**Q&Aは元は `display: grid` でしたが、グリッドはフロートを避けて箱ごと横にずれるだけで写真の下に文章が回り込みません**。そのため通常のブロック＋記号を絶対配置に変更しています。写真を左に流すとその記号が写真に重なるので、回り込みは右で統一しました。767px以下ではフロートを解除して積みます
- 列番号の直書きは不要です。`nth-child` は矢印の送り幅の基準（5枚＝1画面おき）を置くためだけに使っています
- **ループの周期は `data-loop` でJSに渡します**（現在10＝1グループの人数）。折り返しには2周期ぶん要るので、HTML側は10名を2セット持って**1グループ20枚**にしてあります。**人数や段数を変えたら `data-loop` と複製数も直すこと**（段を増やす場合の周期は「段数と人数の最小公倍数」）
- 折り返し後の在庫は2,903px（画面1,440px）と十分です
- **枚数・千鳥・100vh は三つ同時に成立しません。** 1画面の高さ配分は「見出し121px + カード(幅 + 情報欄130px)」で、2段にすると1枚あたり329pxしか使えず、正方形写真だとカード幅が約200pxに制限されて横に6〜7枚並んでしまいます。いまは「カードの大きさ」と「千鳥」を優先し、100vh を外しています
